# Bookstore lab vocabulary

**Safe Baseline**: The initial bookstore application with protections at all five
targeted security boundaries.

**Mutation**: An intentionally introduced weakness for one target CWE, used to
observe ACVIS detection against synthetic data.

**Remediation**: A change restoring the protection removed by a Mutation.

**Expected Rule Reference**: A requester-supplied MongoDB identifier or rule_id
against which an actual ACVIS Scan Result must be compared.
